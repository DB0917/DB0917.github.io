有關莫比烏斯函數的定義請見 [維基百科](https://zh.wikipedia.org/zh-tw/%E9%BB%98%E6%AF%94%E4%B9%8C%E6%96%AF%E5%87%BD%E6%95%B0)

:::success
**求所有 $gcd(i, j) = 1$ 的 $(i, j)$ 個數**

$1 \le i \le N$
$1 \le j \le M$
:::

## 使用莫比烏斯函數的解法 : 

首先列出原式 : 

$$Ans = \sum\limits_{i=1}^n \sum\limits_{j=1}^m \,[\gcd(i, j) = 1]$$

(這邊的括號是**艾佛森括號（Iverson bracket** ) )

首先我們都知道 $\sum\limits_{d | n} \mu(d) = [n=1]$

也就是說，只有在 $n=1$ 的時候 $\sum\limits_{d | n} \mu(d)$ 才會等於 $1$ ， 不然都是 $0$

所以原式等價於這個 : 

$= \sum\limits_{i=1}^n \sum\limits_{j=1}^m \sum\limits_{d|\gcd(i, j)} \mu(d)$

( $d$ 是 $i$ 也是 $j$ 的因數 )

枚舉 $d$

$= \sum\limits_{d=1}^{\min(n, m)} \mu(d) \sum\limits_{i=1}^{\lfloor\frac{n}{d}\rfloor} 1 \sum\limits_{j=1}^{\lfloor\frac{m}{d}\rfloor} 1$

$= \sum\limits_{d=1}^{\min(n, m)} \mu(d) \lfloor \frac{n}{d} \rfloor \lfloor \frac{m}{d} \rfloor$

----

## 使用莫比烏斯反演的解法 :

莫比烏斯反演定義了兩個函式 $F$ 跟 $f$ ， 並且有兩種寫法

寫法 1. 因數寫法

我們定義一個函數 $F$ 滿足以下條件 : 

$F(n) = \sum\limits_{d|n} f(d)$

那麼 $f$ 也一定滿足以下條件 : 

$f(n) = \sum\limits_{d|n} \mu\left(\frac{n}{d}\right) F(d)$

寫法 2. 倍數寫法

我們定義一個函數 $F$ 滿足以下條件 : 

$F(n) = \sum\limits_{n|d} f(d)$

那麼 $f$ 也一定滿足以下條件 : 

$f(n) = \sum\limits_{n|d} \mu\left(\frac{d}{n}\right) F(d)$

----

令 $f(x)$ 為 "$gcd(i, j) = x$" 的 $(i, j)$ 個數

且 $F(x)$ 為 "$gcd(i, j) = kx$" 的 $(i, j)$ 個數 (其中 $k$ 為任意正整數)

並且 $F(x) = \sum\limits_{x|d}f(d)$

藉由莫比烏斯反演可知 :
\begin{gather*}
f(x) = \sum\limits_{x|d}\mu(\frac{d}{x})\ F(d)
\end{gather*}

而且 $F(d)$ 超級好算的!!


\begin{gather*}
F(d) = \lfloor \frac{n}{d} \rfloor \times \lfloor \frac{m}{d} \rfloor
\end{gather*}

最後我們知道題目要求的是找互質數量，因此答案會是 $f(1)$ ，也就是 : 

\begin{gather*}
f(1) = \sum\limits_{1|d}\mu(\frac{d}{1})\ F(d)
\end{gather*}

\begin{gather*}
 = \sum\limits_{d=1}\mu(d) \ F(d)
\end{gather*}

\begin{gather*}
 = \sum\limits_{d=1}\mu(d) \ \lfloor \frac{n}{d} \rfloor \lfloor \frac{m}{d} \rfloor
\end{gather*}

與我們一開始用莫比烏斯函數推導出的結果一模一樣!!

首先可以把塗色方式分為 $1$ 面循環、$d$ 面循環等等...

我們定義 $d | m$ 的 $d$ 面循環的填法數量設為 $f(d)$

但是 $f(d)$ 並不好算 (例如 : $4$ 面循環會不小心算到 $2$ 面循環跟 $1$ 面循環)

大家也知道 隨便填 $x$ 面的話，循環的長度一定是 $x$ 的因數

因此定義 $F(x) = \sum\limits_{d|x}f(d)$ 也就是隨便填 $x$ 面的填法

$F(x)$ 很好算 : $F(x) = c^{n \times n \times x}$

反演後獲得 : $f(x) = \sum\limits_{d|x}\mu{(\frac{x}{d})}F(d)$

題目說了循環後如果長一樣是不算的，因此答案是 : 

$Ans = \sum\limits_{d|m}\frac{f(d)}{d} (mod \space 10^9+7)$

預處理 $\mu$ 後可以在 $O(n + \sqrt{m} \times d(m) \times \log{n})$ 的時間內完成

### AC Code

```C++
vector<int> isp(501, 0), mu(501, 0), ps;
mu[1]=1;
for(int i=2;i<=500;i++){
    if(isp[i]==0){
        isp[i] = i;
        mu[i] = -1;
        ps.push_back(i);
    }
    for(auto& p : ps){
        if(isp[i]<p || p*i>500) break;
        if(isp[i]==p) mu[i*p] = 0;
        else mu[i*p] = mu[i] * mu[p];
        isp[i*p] = p;
    }
}

auto fp = [&](int a, int b) -> int {
    int res = 1;
    while(b){
        if(b&1) res = (res * a) % MOD;
        a = (a * a) % MOD;
        b>>=1;
    }
    return res;
};

auto inv = [&](int a) -> int {
    return fp(a, MOD-2);
};

int n, m, c; cin >> n >> m >> c;
vector<int> f(m+1), facs;
for(int i=1;i*i<=m;i++){
    if(m%i==0) facs.push_back(i);
    if(m%i==0 && i*i!=m) facs.push_back(m/i);
}

int ans=0;
for(auto& e : facs){
    int sum=0;
    for(int i=1;i*i<=e;i++){
        if(e%i==0) sum = ((sum + mu[e/i] * fp(c, n*n*i)) % MOD + MOD) % MOD;
        if(e%i==0 && i*i!=e) sum = ((sum + mu[i] * fp(c, n*n*e/i)) % MOD + MOD) % MOD;
    }
    ans = (ans + sum * inv(e)) % MOD;
}
cout << ans << '\n';
```
